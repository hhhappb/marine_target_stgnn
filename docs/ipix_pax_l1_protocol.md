# IPIX PAX-L1 协议

2026年9月28日说明：本文件保留P=16的位置增强协议定义。最近本地P=8、70轮完整配对见 [IPIX当前实验协议](ipix_experiment_protocol.md)，不得与本文件混称。

状态：唯一正式 IPIX 位置增强难度协议

协议名称：`IPIX PAX-L1`

协议标识：`ipix_pax_l1_v1`

## 固定定义

- 数据：Dartmouth IPIX，14 个文件，HH/HV/VV/VH 四种极化，共 56 个独立文件-极化条件。
- 输入：`P=16` 连续脉冲。
- 划分：每个文件-极化条件内部按预处理窗口顺序前 60% 训练、后 40% 测试。
- 标签：训练和测试均使用 `primary_strict`，仅 `range_role == 2` 的唯一主目标距离单元为 target。
- 训练增强：在复数回波上在线执行非循环 `clutter_fill` 距离平移，`max_shift=3`，包含恒等位移。腾空距离单元由真实 clutter 回波填充，标签清零。
- 测试增强：无。
- 阈值：仅由训练集 clutter 分数的序统计量确定，名义 `Pfa=0.001`。
- 判决：`o0 = softmax(logits)[:, 0, :]`，`o0 <= threshold` 判为 target。
- 主指标：测试 PD。测试 actual PF 仅作诊断，不参与模型排序或性能结论。
- 公平性：所有对比模型，包括 Original ST-GNN，使用完全相同的数据、划分、标签、训练增强和评价流程。

## 覆盖层

- P=16、完整 56 条件是正式结果层。
- 单条件运行仅是该协议的调试或验证子集，不构成新协议。
- 其他脉冲数、跨文件训练测试划分或不同平移范围均不属于 PAX-L1。

## 明确排除

`P=4`、HH 单极化、17 到 30 或 30 到 17 跨文件划分、`max_shift=13`、不包含恒等位移的旧实验已于 2026-09-11 退役。其配置和非保护目录产物已删除；受保护的历史训练日志仅保留审计用途，不得用于论文、报告、模型选择或后续实验。

正式实现以 `e4d2_gdcm/experiments/run_v21_ipix.py` 为准。
