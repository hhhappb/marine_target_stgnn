## 4. 关键发现与待确认项

1. **杂波功率定义存在 13 dB 的口径分叉**：文档字面“平均功率”= Σ/(P·M)；而现有 v1.1 代码（e4d2_gdcm / stgnn sdrdsp / SE 各自实现）为 Σ/P，等于 20×平均，即**标称 SCR 实际比字面定义高约 13 dB**。两种口径下结果差异巨大（见 §2 vs §3），因此这是必须由你确认的第一优先项。
2. **“20 epochs”在本代码体系里等于 20 个优化步**（每“epoch”= 1 个 batch 24，非全量一遍）。文档将其定位为“快速筛选、判断候选方向是否具正向信号”，故绝对 PD 偏低属预期，不能当作最终性能；如需可比较的最终数字，应与 Original 在同一 20 步预算下配对比较。
3. 文档其余条款（seed42、min-loss 选点、批内 SCR 均衡轮换、确定性、每目标独立 φ0、随机参考单元、P99 训练集拟合）均已按字面落实。
4. 实测 PF（−18 dB 组杂波单元，诊断用）——文档字面口径：{'0.0001': 0.00015, '0.001': 0.00097, '0.01': 0.01025}；v1.1 口径：{'0.0001': 0.0, '0.001': 0.00017, '0.01': 0.00766}。
