# RawPolar-E4-RDJ 与 RawCS-E4-RDJ —— 设计思路、数据流与基线对比报告

- **适用模型**: `e4d2_raw_polar`（RawPolar-E4-RDJ）、`e4d2_raw_cs`（RawCS-E4-RDJ）
- **基线**: `e4d2_RDJ`（E4-D2-RDJ，统计特征 E4 主干）
- **协议**: v1.0（φ0=0 固定初始相位）—— 本文报告为该协议下的设计与结果
- **训练配置**: 200 epochs × 3 seeds (42/123/456)，BS=24，Adam lr=0.001，加权 CE w=[1,10]，SCR-uniform 采样
- **实验脚本**: `run_rawcs_comparison.py`，结果 `checkpoints/rawcs_comparison.json`

---

## 1. 设计思路

### 1.1 研究动机：从"手工统计特征"到"原始复回波表征"

统计型 E4 主干使用 8 维 Cell 统计特征（rms/p95/mean/std/contrast/temporal_mean/temporal_std/phase_stability）与 PL/RPH 等手工特征。这类特征有两个局限：

1. **信息瓶颈**：4 个脉冲的全部相位演化被压缩成 `temporal_mean / temporal_std / phase_stability` 三个统计量，跨脉冲的细粒度相位结构（如 Doppler 相位差）被丢失或手工建模；
2. **设计偏见**：`phase_stability = 1 − std(angle)/π` 等假设相位稳定即目标，可能不匹配真实海杂波。

**核心假设**：与其手工设计统计特征，不如把**原始复回波的极坐标表征**直接交给网络，让网络自己学习"脉冲间的相位演化规律"。

### 1.2 RawPolar-E4-RDJ（第一版：原始极坐标）

对每个接收回波样本 `r = c + s`，按距离单元逐脉冲取极坐标：

```
A   = |X| / P99                   归一化幅度
cosθ = I / |X|,  sinθ = Q / |X|   单位相位方向
```

输入：

| 输入 | 形状 | 含义 |
|------|------|------|
| x_main | [B,4,P,N] | I/P99, Q/P99, PL_raw, RPH/P99（主干保留） |
| x_polar_amp | [B,1,P,N] | 每脉冲归一化幅度 A |
| x_polar_phase | [B,2,P,N] | 每脉冲相位方向 [cosθ, sinθ] |
| x_global | [B,6] | 全局杂波统计 |

核心组件 **RawPhaseEncoder** 用三层时序卷积 `2→32→64→128`（时序维 4→2→1）**自学习脉冲相位演化**，替换统计型 PhaseEncoder 的 3 个手工统计量：

```
[cosθ, sinθ] ∈ R^{B×2×4×N}
  → Conv2d(2→32, k=(3,1))        [B,32,4,N]
  → Conv2d(32→64, k=(3,1), s=2)  [B,64,2,N]
  → Conv2d(64→128, k=(3,1), s=2) [B,128,1,N]
  → squeeze → F_phase [B,128,N]
```

**RawAmpEncoder** 同理提取幅度演化 `1→16→32→64` → `F_amp [B,64,N]`。

### 1.3 RawCS-E4-RDJ（第二版：幅相可信度门控）

**动机**：Raw-Polar 有一个已知缺陷 —— 当幅度 A≈0（噪声主导）时，`[cosθ, sinθ]` 是无意义的随机方向。此时把"随机相位"喂给网络不仅无信息，还会引入噪声。

**改进**：用幅度作为相位可信度，对相位方向加权：

```
g(A) = A / (A + τ),   τ = 0.1 × P99

C_g = g(A)·cosθ,   S_g = g(A)·sinθ
```

- 弱幅度 → g(A)→0 → 相位贡献被抑制（不可信相位不参与）；
- 强幅度 → g(A)→1 → 相位方向完整保留；
- g(A) 单调且光滑，可作为网络的自适应相位可信门控。

与 `compute_cs_polar`（`e4d2_raw_cs/utils/preprocess.py`）实现一致：

```python
g  = A / (A + tau)                                  # [B,P,N] 可信度
Cg = g * X.real / (A + eps)                         # g(A)·cosθ
Sg = g * X.imag / (A + eps)                         # g(A)·sinθ
```

## 2. 数据流

### 2.1 总体链路

```
海杂波 c ──→ 注入目标 s_p = A·exp(j(4π·v·PRT·p/λ + φ0))
              ↓
      接收回波 r = c + s   （φ0=0 固定，v1.0 协议）
              ↓
      I = Re(r), Q = Im(r)
              ↓
   ┌────────────────────────────────────────────┐
   │  RawPolar:  A=|r|/P99, [cosθ,sinθ]=[I/A,Q/A]│
   │  RawCS:     C_g=g(A)cosθ, S_g=g(A)sinθ      │
   └────────────────────────────────────────────┘
              ↓
   RawAmpEncoder(1→16→32→64) → F_amp [B,64,N]
   RawPhaseEncoder(2→32→64→128, 4→2→1) → F_phase [B,128,N]
              ↓
   CVOCAFusion(F_amp, F_phase) → F_ap [B,64,N]
   （A=softplus(proj), [C,S]=L2norm, Z=A·C+jA·S, ComplexConv）
              ↓
   concat[ STGNN(x_main)=1024, F_ap=64, GlobalMLP=128 ] = 1216ch
              ↓
   RdjDetector（差异判决）→ logits [B,2,N]
```

### 2.2 与统计型 E4-D2-RDJ 的差异

| 环节 | E4-D2-RDJ（统计型） | RawPolar / RawCS |
|------|------|------|
| 相位编码输入 | 3 个统计量（temporal_mean/std/phase_stability） | 原始 [cosθ, sinθ] 或 [g(A)cosθ, g(A)sinθ] |
| 相位编码器 | PhaseEncoder: Conv1d(3→64→128) | RawPhaseEncoder: Conv2d(2→32→64→128) 时序 4→2→1 |
| 幅度编码输入 | amp_map + 4 个 Cell 统计量 | 原始每脉冲幅度 A |
| 幅度编码器 | AmpEncoder: Conv2d+Conv1d 融合 | RawAmpEncoder: Conv2d(1→16→32→64) |
| CVOCA / 全局 / 检测头 | 相同 | 相同（完全一致） |

两模型参数量均为 **4,437,954**（较统计型 4,442,338 少约 4K，差异仅来自编码器通道结构），保证对比公平。

### 3.3 旧协议下的初步解读（后经审计修正）

- **RawCS 的 −24 dB 起步优势巨大**（PFA=1e-3 下 0.664 vs 统计型 0.191）——远超幅相融合应有的合理增益；
- RawPolar 在低 PFA 反而不如统计型（1e-4 下 0.414 < 0.516），说明原始相位方向在低 SCR 噪声区噪声大；
- **RawCS 的 g(A) 门控把"相位不可信区"抑制后反而大幅提升** —— 这个反常信号是审计 RawCS 的起点。

> ⚠️ **重要**：本报告的 v1.0 结果已被后续审计推翻（见《RawCS 排查报告》）。φ0=0 固定相位为目标注入引入了"绝对相位捷径"，上表所有数字在真实物理意义下均偏高，**不应作为最终论文结论**。
