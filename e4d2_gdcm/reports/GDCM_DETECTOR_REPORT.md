## 1. 设计：分组归一化的方向与通道级幅度

U_d、U_h ∈ [B,128,R]（GroupNorm 8 groups）。把 128 通道按 G=8 组、C_g=16 划分：

```
Δ = U_d − U_h
ρ_g = RMS(Δ_g) = sqrt((1/16)Σ_{c∈g}Δ²_c + ε)      [B,8,R]   组内 RMS
D_s,c = Δ_c / (ρ_{g(c)} + ε)                        [B,128,R] 组归一化方向
D_a,c = |Δ_c| / (|U_d,c| + |U_h,c| + ε)             [B,128,R] 通道级相对强度 ∈[0,1]
```

- **D_s**：组内相对方向（哪些通道增强/减弱），整体强度被剥离（Δ_g→kΔ_g 不变）；
- **D_a**：CFAR 式相对异常——CUT 偏离占 CUT 与背景总响应尺度的比例。

**判决分类器与 RDJ 完全一致**（concat→Conv1d→128→GELU→Dropout→Conv1d(128→2)），
保证性能变化可归因于 D_s/D_a 重新定义。

## 4. 结论

1. **G3（组归一化方向 + log(1+|Δ|)）全面最优**：PdL@1e-4=0.518、@1e-3=0.600、@1e-2=0.718，三个 PFA 全部超越 G0（+0.058 / +0.060 / +0.044），AUC=0.9830 也最高。**验证了"低 PFA 容易被极端杂波 outlier 控制"的假设**——log 压缩抑制 hardest clutter tail 后，低 PFA 检测率显著提升。
2. **上一轮 DA 失败的归因确认**：G1（组归一化方向 + **保留完整 |Δ|**）PdL@1e-3=0.576 超过 G0（0.540），而 DA 轮把 D_a 压成单通道（F2/F3）后 PdL 全面低于 F0。**结论：方向归一化本身有效，DA 的失败确实源于强度信息被压缩**。G1 用"组内归一化方向 + 完整通道级幅度"修复了这个问题。
3. **G2（相对强度 |Δ|/(|Ud|+|Uh|)）未带来提升**（0.527 < 0.540）：相对化压缩了幅度尺度信息，与绝对 |Δ| 相比低 SCR 判别力略降——CFAR 式相对量的理论优势在此协议下未兑现。
4. **G4（组级幅度 8ch→136 总通道）有效且省参数**：PdL@1e-3=0.564 > G0，参数还少 15K。说明把幅度压到组级（每 16 通道一个 RMS）仍保留足够强度信息。
5. **推荐（最终采用 A0）**：综合后续"Why D_s"四组实验与稳定性权衡，**最终采用 A0（仅通道级 log 强度 D_a=log(1+|Δ|)，128ch）**——AUC 0.9842±0.002 为全变体最高且方差最小，PdL@1e-3/1e-2 与 G3 持平（0.600/0.718）。已设为包默认 `E4D2()` → `gdcm_a0`。组方向变体 G1-G4 保留作消融对照。
