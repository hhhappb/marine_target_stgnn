### 3.3 SCR 注入公式 (论文 Equation 17)

\[
\text{SCR} = 10 \log_{10}\left(\frac{\sigma_t^2}{\sum_{m=1}^{M} \sigma_m^2}\right),\quad M=20
\]

- \(\sigma_m\) = 第 \(m\) 个参考距离单元的幅度（单脉冲）
- \(\sigma_t\) = 目标幅度（每脉冲相同，通过 Doppler 相位区分不同脉冲）
- 分母 = 每脉冲 20 个参考单元幅度平方和，再对 P=4 个脉冲取平均

**实现**:
```python
# 正确: (Σ_p Σ_m |x[p,m]|²) / P = M · mean_over_all
cp = np.sum(np.abs(x[:, ref_indices]) ** 2) / P
amp = np.sqrt(cp * 10 ** (SCR / 10.0))
```

| 版本 | 公式 | 目标幅度相对论文 | SCR 偏差 |
|------|------|:---:|:---:|
| 论文 Eq.17 | \(\sum_p\sum_m \|x\|^2\ /P = M·\bar{P}\) | 1.0× | 0 dB |
| 最初 (sum) | \(\sum_p\sum_m \|x\|^2 = 80·\bar{P}\) | 2.0× | +6 dB (目标过强) |
| 中间修复 (mean) | \(\frac{1}{80}\sum_p\sum_m\) | 0.224× | −13 dB (目标过弱) |
| **当前 (sum/P)** | \(M·\bar{P}\) | **1.0×** | **0 dB ✓** |

## 4. 模型架构 (E4-D2)

```
                     ┌────────────────── ST-GNN 主干 ──────────────────┐
X_main [4,P,N] ────►│ Conv2d(4→32→64) → STFE×2(64→128→512) → TFE×2   │
                     │ → squeeze pulse → F_main [B,1024,N]             │
                     └─────────────────────────────────────────────────┘

X_phase_cell [3,N] ─► PhaseEncoder: Conv1d(3→32→64) → F_phase [B,64,N]

X_amp_map [1,P,N] ──┐
                     ├► AmpEncoder: Map Conv2d(1→16→32,squeezeP)  ─┐
X_amp_cell [4,N] ────┘             Cell Conv1d(4→32)               ├► [64,N]
                                                                    │
           ┌──────────────── CVOCA Polar Fusion ───────────────────┘
           │  A = softplus(Conv_amp(F_amp))           → 非负幅度
           │  [C, S] = L2_norm([cos_conv, sin_conv](F_phase)) → 单位相位
           │  Z_real = A·C,  Z_imag = A·S              → 复值重构
           │  F_ap = concat(Z_real, Z_imag, |Z|)       → [B,64,N]
           └────────────────────────────────────────────────────────

Global [6] ────────► MLP(6→32→128) → broadcast → F_global [B,128,N]

F = concat([F_main(1024), F_ap(64), F_global(128)]) = [B,1216,N]

                     ┌────────── Local-CFAR Detector Head (D2) ─────────┐
                     │  Conv1d(1216→256, k=1)                           │
                     │  ┌─ DepthwiseConv1d(k=3, groups=256)  → 256ch ─┐ │
                     │  ├─ DepthwiseConv1d(k=7, groups=256)  → 256ch  ├┤
                     │  └─ DepthwiseConv1d(k=15, groups=256) → 256ch ─┘ │
                     │  Concat(768) → Conv1d(768→512) → GELU            │
                     │  Conv1d(512→2) → logits [B,2,N]                  │
                     └──────────────────────────────────────────────────┘
```

### 4.1 组件参数表

| 组件 | 输入 | 输出 | 说明 |
|------|------|------|------|
| ST-GNN 主干 | `[B,4,4,256]` | `[B,1024,256]` | STFE(4→128→512) + TFE(128→256,512→1024) |
| PhaseEncoder | `[B,3,256]` | `[B,64,256]` | Conv1d(3→32→64), ReLU |
| AmpEncoder | Map: `[B,1,4,256]` + Cell: `[B,4,256]` | `[B,64,256]` | 双路 → concat(64) → Conv1d(64→64) |
| CVOCA Fusion | Amp(64) + Phase(64) | `[B,64,256]` | 极坐标 `A·exp(jθ)` + 复值耦合 |
| Global MLP | `[B,6,256]` | `[B,128,256]` | Conv1d(6→32→128) 广播 |
| Detector (D2) | `[B,1216,256]` | `[B,2,256]` | 多尺度邻域深度可分离卷积 |
| 总参数量 | | **4,311,138** | (4.31M, 比 ST-GNN 少 15%) |

### 4.2 GAT 图结构

```
邻接矩阵 A[i,j] = 1  if |i − j| ≤ 1  (三对角, 仅邻近距离单元)
              = 0  otherwise
```

### 4.3 核心创新点 (对比基线 ST-GNN 2ch)

| 维度 | ST-GNN 2ch | E4-D2 |
|------|:---:|:---:|
| 输入通道 | 2 (I, Q) | 17 (4主干+3相位+1+4幅度+6全局) |
| 特征提取 | 仅 ST-GNN 主干 | ST-GNN 主干 + 3 个并行 Encoder |
| 模态融合 | 无 | CVOCA 极坐标 `A·exp(jθ)` 耦合幅-相 |
| 检测头 | Conv1d(1024→512→2) | Local-CFAR: 多尺度邻域卷积 (k=3/7/15) |
| 参数量 | 5,066K | **4,311K (−15%)** |
| 理论来源 | ST-GNN 论文 | ST-GNN + CVOCA 复值耦合 + CFAR 邻域建模 |

## 6. 虚警率 (FAR) 控制

| 项目 | 设置 |
|------|------|
| FAR 控制器 | 论文公式 (Eq.15): 阈值 = 第 ⌈α_f · N_c⌉ 个排序杂波分数 |
| 校准数据 | **训练集全部杂波单元** (v1.1, Eq.15) — N_c = 6,093,276；无独立无目标校准集 |
| 评估 PFA | **0.0001, 0.001, 0.01** (3 水平) |
| 阈值来源 | **仅训练集** (无测试数据泄漏) |

### 校准流程

```
1. 取训练集全部杂波距离单元（目标注入后 label=0 的单元）
2. 前向传播 → 杂波概率 o_c(0) [N_c = 6,093,276 个距离单元]
3. 升序排列 → o_sorted = sort(o_c)
4. 阈值 h = o_sorted[⌈α_f · N_c⌉ − 1]
5. 测试时: o(0) ≤ h → 目标; o(0) > h → 杂波
```

## 9. 实验 A/B/C/D/E 系列与 E4-D2 的关系

E4-D2 是多次消融实验的最终结论产物：

| 阶段 | 实验 | 关键发现 |
|------|:---:|------|
| **A** | PL/RPH 预处理消融 | RPH/P99 优于 RAW (A2), RPH 除以 P99 后值域压缩保留物理含义 |
| **B** | Cell 特征子集消融 | 3ch 相位组 ≥ 8ch 全特征 (B1=B0), 幅度特征不能简单拼接入 Cell |
| **C** | PL/RPH 融合位置 | Early concat 仍为最优 (C0), Late/Gated 未超越 |
| **D** | Global 融合方式 | Residual FiLM AUC=0.989 但 PdL 低于 concat; concat 最稳定 |
| **E** | Amp-Phase 解耦融合 | CVOCA `A·exp(jθ)` 极坐标耦合唯一有效利用幅度; 多尺度 Local-CFAR 头 (D2) 在 10/10 seeds 中优于简单头 |
| **T0** | 三优组合 | A2+B5+D3 无协同增益 (AUC=0.983, 种子方差大), 不如独立优化 |

E4-D2 采用的配置: A2 (RPH/P99) + B1 (3ch 相位组) + D1 (Global concat) + E4 (CVOCA) + D2 (Local-CFAR)。
