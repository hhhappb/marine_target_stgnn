# RawCS-E4-RDJ 性能排查报告 —— 绝对相位捷径的发现与协议修订

- **排查对象**: RawCS-E4-RDJ（`e4d2_raw_cs`）
- **触发原因**: v1.0 协议（φ0=0 固定初始相位）下 RawCS 取得 AUC=0.9997、PdL@1e-3=0.913，远超合理范围
- **排查脚本**: `run_rawcs_audit.py`，结果 `checkpoints/rawcs_audit.json`
- **协议修订后重跑**: `run_rawcs_comparison_phirand.py`，结果 `checkpoints/rawcs_comparison_phirand.json`

---

## 1. 排查框架（四项假设）

| # | 假设 | 排查手段 | 结论 |
|---|------|----------|:---:|
| ① | RawCS 的 C/S 输入直接泄漏了仿真目标分量/相位 | 逐行审查 `compute_cs_polar` | **排除** |
| ② | 固定初始相位 φ0=0 造成"绝对相位捷径" | φ0 随机化重训 + 全局相位旋转测试 | **证实** |
| ③ | 模型依赖"绝对相位方向"而非相对相位结构 | 测试集全局随机相位旋转 e^{jψ} | **决定性证据** |
| ④ | 目标位置固定引入位置/局部背景偏置 | 测试位置随机化 U(20,235) | 轻微，非主因 |

---

## 2. 排查①：C/S 标签泄漏检查（排除）

逐行审查 [compute_cs_polar](file:///tmp/ST-GNN/e4d2_raw_cs/utils/preprocess.py#L154-L188)：

```python
X = X_complex                    # 仅接收回波 r = c + s
A = np.abs(X)
g = A / (A + tau)
Cg = (g * X.real / (A + eps))    # g(A)·cosθ
Sg = (g * X.imag / (A + eps))    # g(A)·sinθ
```

**结论**：C_g、S_g 仅由接收回波 `I=Re(r), Q=Im(r)` 与幅度门控计算，全程未接触仿真目标分量 s、目标 Doppler 相位、target mask 或目标位置。**输入通道无标签泄漏**。假设①排除。

---

## 3. 排查② + ③：固定 φ0 与全局相位旋转（证实 + 决定性证据）

### 3.1 实验设计

- **模型 A**：φ0=0 训练（原协议），seed 42
- **模型 B**：φ0~U(-π,π) 每样本独立随机训练，3 seeds (42/123/456)
- **旋转测试**：对测试样本乘 `e^{jψ}, ψ~U(-π,π)`。此变换下幅度、SCR、脉冲间相位差、Doppler、标签**全部不变**，物理上仍是同一检测问题；唯一改变的是绝对相位方向。

### 3.2 结果

| 场景 | AUC | PdL@1e-4 | PdL@1e-3 | PdL@1e-2 |
|---|---|---|---|---|
| A: φ0=0 固定位（原协议） | **0.9993** | 0.494 | **0.798** | 0.943 |
| A: φ0=0 + 全局相位旋转 | **0.4677** ↓↓ | 0.111 | **0.229** | 0.320 |
| B: φ0~U 固定位（3 seeds） | 0.9708±0.014 | 0.218 | **0.390** | 0.549 |
| B: φ0~U + 全局相位旋转 | 0.9682 | 0.208 | **0.416** | 0.587 |
| B: φ0~U + 随机位置 U(20,235) | 0.9535 | 0.176 | **0.307** | 0.427 |

### 3.3 判定

**决定性证据（旋转实验）**：φ0=0 模型在全局相位旋转后 **AUC 从 0.9993 崩到 0.4677（≈随机 0.5）**，PdL@1e-3 从 0.798 跌至 0.229。由于旋转不改变任何物理信息（幅度/SCR/Doppler/标签均不变），唯一的解释是：

> **模型 A 学到的是"目标相位必须落在特定绝对方向"这一仿真特有的模式，而非目标的真实物理结构（跨脉冲相干性）。**

**佐证（φ0 随机化）**：仅将训练 φ0 随机化（其余设置全不变），性能立即回落：AUC 0.9993→0.9708、PdL@1e-3 0.798→0.390。且随机化后的模型 B 对全局旋转**完全鲁棒**（AUC 0.9708→0.9682，PdL@1e-3 0.390→0.416 几乎不变），说明它已学到真正的相对相位结构。

**假设②③证实**：RawCS 在 v1.0 下的优异表现主要来自固定 φ0 的绝对相位捷径。

---

## 4. 排查④：目标位置固定偏置（轻微）

模型 B 在固定位 128 vs 随机位 U(20,235) 下：AUC 0.9708→0.9535，PdL@1e-3 0.390→0.307。差异存在但温和，位置/局部背景偏置**不是主因**。

---

## 5. 发现的问题（汇总）

1. **根因**：目标注入 `s_p = A·exp(j(4π·v·PRT·p/λ + φ0))` 中 φ0 恒为 0，导致 p=0 脉冲的目标相位永远指向实轴正方向。所有训练/测试目标共享同一绝对相位模板，RawCS 学到"出现该相位方向即目标"。
2. **影响**：v1.0 下所有幅相类模型的绝对性能数字均被高估，**不可作为论文结论**。
3. **C/S 本身无泄漏**：输入变换合法，问题完全出在仿真目标注入协议。

phi0 = np.random.uniform(-np.pi, np.pi)   # 每样本
s_p = A · exp(1j·(4π·v·PRT·p/λ + phi0))

## 7. 前后对比与最终结论

### 7.1 RawCS 前后对比

| 指标 | v1.0（φ0=0） | v1.1（φ0~U） | 变化 |
|------|------|------|------|
| AUC | 0.9997 | 0.9699 | −0.030 |
| PdL@1e-3 | 0.913 | 0.270 | **−0.64** |
| PdL@1e-4 | 0.700 | 0.140 | −0.56 |

### 7.2 最终结论

1. **RawCS 的 v1.0 优异表现（AUC=0.9997 / PdL@1e-3=0.913）不可信**，其主体来自固定 φ0=0 的绝对相位仿真捷径 —— 全局相位旋转后 AUC 崩至 0.468（≈随机）是铁证。
2. **消除捷径后 RawCS 的真实水平**约为 AUC≈0.97 / PdL@1e-3≈0.27，且已对全局相位旋转鲁棒（具备物理可迁移性）。
3. **v1.1 下模型排序反转**：统计型 E4-D2-RDJ 全面领先（AUC=0.9812、PdL@1e-3=0.540、方差最小 ±0.002），因其统计特征天然对绝对相位不变；幅相类模型在低 SCR 区明显吃亏。
4. **协议要求**：任何目标注入必须每样本独立随机 φ0~U(-π,π)，否则结果不可信。

### 7.3 后续建议

- 若论文主推幅相类模型，需解决"随机 φ0 下低 SCR 弱检测"问题（如显式跨脉冲相位差输入、增大脉冲数 P、相位差相对化预处理）；
- 否则以统计型 E4-D2-RDJ 作为当前最佳基线；
- v1.0 的所有幅相类历史结果已作废，不可引用。
