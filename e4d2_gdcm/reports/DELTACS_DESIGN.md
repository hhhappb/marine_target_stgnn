# DeltaCS-E4-RDJ —— 相对相位差设计报告

- **模型包**: `e4d2_delta_cs`
- **对比基线**: `e4d2_RDJ`（E4-D2-RDJ）、`e4d2_raw_polar`（RawPolar-E4-RDJ）
- **协议**: v1.1（目标注入 φ0~U(-π,π) 每样本随机，训练/测试一致）
- **训练**: 200 epochs × 3 seeds (42/123/456)，BS=24，Adam lr=0.001，加权 CE w=[1,10]
- **脚本**: `test_delta_cs_invariance.py`（数值检查）、`run_deltacs_comparison.py`（对比实验）

## 1. 动机：从绝对相位到相对相位

RawCS / Raw-Polar 的相位输入是**绝对相位方向** [cosθ, sinθ]。RawCS 审计（`RAWCS_AUDIT_REPORT.md`）已证实：固定 φ0 的仿真协议下，模型可以学到"目标相位指向特定绝对方向"这一捷径；即使 φ0 随机化，绝对相位表征仍包含与物理无关的全局旋转自由度。

**设计保证**：DeltaCS 只保留相邻脉冲的**相位差**：

```
D_{p,r} = X_{p,r}·X_{p-1,r}^* = A_p·A_{p-1}·e^{j(θ_p − θ_{p-1})}
C_Δ = Re(D/|D|),  S_Δ = Im(D/|D|)
```

全局相位旋转 `X → X·e^{jψ}` 在相位差中被完全抵消：

```
DeltaCS(X·e^{jψ}) = DeltaCS(X)
```

网络因此**不可能**利用绝对相位捷径，只能学习真正有物理意义的跨脉冲相对相位结构（Doppler 相位差）。

## 2. 实现要点

- **复共轭乘积**直接计算，避免 θ 提取与 −π↔π 相位跳变处理；
- **首位置零补齐**：`C_Δ = [0, cosΔθ01, cosΔθ12, cosΔθ23]`，输入保持 [B,2,4,N] 与 RawCS 完全同形，**RawPhaseEncoder 零改动**；
- **数值保护**：`denom = |D|.clamp_min(1e-6)`，不加新的幅度门控（与 RawCS 公平对比）；
- 幅度分支、CVOCA、Global、RDJ 检测头全部保持与 RawCS 一致（参数量同为 4,437,954）。

## 5. 结论

1. **设计保证成立**：DeltaCS 在数值层面（1e-8）与端到端（AUC 0.9773→0.9780）均对全局相位旋转不变，彻底封堵绝对相位捷径。
2. **性能定位**：v1.1 协议下 DeltaCS（PdL@1e-3=0.317）**优于 RawCS（0.270）、接近 RawPolar（0.336）**，但仍低于统计型 E4-D2-RDJ（0.540）。
3. **改进方向**：DeltaCS 在低 SCR（≤−16 dB）仍弱于统计型。可能的提升路径：相位差输入叠加幅度门控 g(A)（注意与 RawCS 公平性）、增大脉冲数 P、或与统计特征并联融合。
4. **诚实结论**：相对 RawCS/RawPolar 的绝对相位系，DeltaCS 以轻微性能代价换来最强物理可迁移性（旋转免疫）；统计型仍是当前 SDRDSP 协议下的最优基线。
